## ⚡ The 7-Stage Experience Breakdown & New Upgrades

1. **Stage 01: Futuristic Terminal Boot-Up**
   - Carbon Cyberpunk Terminal with live streaming diagnostics and CRT scanline telemetry:
     `> QUANTUM HASH: 0x7E49A29F_DEVANSH`
     `> STATUS: TOP-SECRET CLASSIFIED DOSSIER FOUND`
   - Initiation button takes Devansh to the in-display biometric gate.

2. **Stage 02: In-Display Thumbprint Verification (Ergonomic Sensor + Haptics)**
   - **Positioned Near the Bottom:** Exactly where real in-display optical/ultrasonic fingerprint sensors sit on modern Android smartphones!
   - **Full Human Thumbprint SVG:** Detailed anatomical whorl, arch, and loop papillary ridges.
   - **Android Vibration Haptics:** Resting the thumb triggers physical vibration pulses (`navigator.vibrate`) that intensify in frequency as the progress bar fills over 1.4s.
   - Upon reaching 100%, flashes green with a heavy tactile unlock click:
     `[ MATCH CONFIRMED: DEVANSH // LEVEL 10 ACCESS GRANTED ]`

3. **Stage 03: Matrix Glitch Reveals DEVANSH**
   - Cascading digital code rain in the background.
   - Rapid-fire cryptographic shuffle: Random hex and cyber glyphs scramble before locking letter-by-letter with mechanical cyber-clicks and micro-haptic ticks into:
     **D → E → V → A → N → S → H**
   - Neon cyan and hot magenta lens flares ignite!

4. **Stage 04: Classified Birthday Dossier & Scratchable Redaction Bars**
   - Top-Secret agency folder with red `CONFIDENTIAL` stamp.
   - **Interactive Redaction Tape:** Sensitive fields are covered by black caution tape bars `[ TAP TO DECLASSIFY ]`.
   - Devansh taps or scratches each bar to peel it away, revealing personal strengths and directives!

5. **Stage 05: Real 35mm Celluloid Film Burn Transition & Countdown**
   - The UI undergoes an astonishing live transformation:
     - Real **Film Burn Effect** melts and bubbles the center of the frame with burning celluloid edges.
     - Background shifts into Warm Velvet Burgundy and 35mm film grain.
     - Audio transitions from cyber drone to analog vinyl surface crackle & 35mm projector whirring.
     - Classic Hollywood circular countdown leader ticks down: `5... 4... 3... 2... 1...` with synchronized cinema bleeps and haptics!

6. **Stage 06: Birthday Movie Premiere & Tearable Golden VIP Ticket**
   - Widescreen letterbox cinema presentation (`Bodoni Moda` & `Playfair Display`).
   - Overhead projector light cone beam with floating golden dust motes and cascading fireworks.
   - **Tearable VIP Cinema Ticket:** Devansh taps/swipes the perforated ticket line to tear his VIP ticket in two with a realistic paper rip sound and haptic vibration!
   - **Photo Frame Slot:** Reel 02 is ready for an optional photo at `assets/images/devansh.jpg`, with an elegant golden star silhouette fallback if no image is present.
   - Staggered heartfelt birthday tribute presented as classic movie dialogue.

7. **Stage 07: Personal Birthday Letter & 3D Wax Seal with "D" Monogram**
   - Aged typewriter parchment letter:
     *"Some people make ordinary moments special just by being around. I'm glad I got to know you, Devansh. Wishing you an amazing year ahead. Never stop exploring, learning, and becoming the person you want to be."*
   - **Interactive Wax Seal:** Tapping the official crimson seal presses down with a heavy tactile stamp thud (`navigator.vibrate`), physically stamping a golden embossed monogram **"D"**!
   - **One-Tap "Save Birthday Dossier":** Automatically renders and downloads a high-res souvenir card directly to Devansh's Android gallery.
   - `[ RE-PLAY FEATURE FILM ↺ ]` allows experiencing the journey again from the beginning.

## 🛰️ Squad Share & MongoDB Telemetry System

When Devansh shares the experience with his friends or anyone opens the link, the system captures deep telemetry and logs it directly into your **MongoDB database**:

### 📊 Telemetry Metrics Collected
1. **Identity & Interactivity**:
   - Unique Visitor UUID (`visitorId`) & Visit Count (`visitCount`)
   - Squad Agent Codename & Birthday Wish (via the Stage 07 Guestbook Ledger)

   - Client Public IP Address
   - City, State/Region, Country, Timezone, and ISP
3. **Hardware & Sensors**:
   - Device Type (Mobile / Tablet / Desktop)
   - Operating System & Version (e.g., Android 14, iOS 17, Windows 11)
   - Browser & Version (Google Chrome, Apple Safari, Samsung Internet, etc.)
   - Device RAM in GB (`navigator.deviceMemory`, e.g. 4GB, 8GB)
   - CPU Cores (`navigator.hardwareConcurrency`)
   - Screen Resolution & Pixel Ratio (e.g. 1080x2400 @ 2.625x)
   - Battery Percentage & Charging State (`navigator.getBattery()`)
   - Network Speed & Type (4G, WiFi, Downlink Mbps, RTT)

## 🚀 How to Run with MongoDB

### 1. Add your MongoDB URI in `.env`
Open the `.env` file in the project root:
```env
MONGO_URI=mongodb+srv://<username>:<password>@cluster0.xxxxx.mongodb.net/devansh_archive?retryWrites=true&w=majority
PORT=5000
```

### 2. Start the Backend Server
```bash
npm start
```
- Frontend + Backend will be live at: `http://localhost:5000`
- **Instant Stats Summary (No Admin Panel needed!)**: `http://localhost:5000/api/stats/summary`

## 🌐 Deploying with Netlify Serverless Functions (100% Free)

1. Push this repository to GitHub or use [Netlify Drop](https://app.netlify.com/drop).
2. In Netlify Site Settings > **Environment Variables**, add:
   - Key: `MONGO_URI`
   - Value: `your_mongodb_connection_string`
3. Netlify automatically runs `netlify/functions/track.js` on every visit, logging all squad visitor data to your MongoDB database for free with **zero server maintenance**!
